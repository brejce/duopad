## 第 4 段：三条特性的措辞依据

不建议写「强大」「丝滑」这类形容词 —— 观众看不出差别。这三条都能验证：

| 字幕 | 依据 |
|---|---|
| `1  真实系统鼠标` + `uinput 注册的真鼠标，不是画的箭头` | `dumpsys input` 里是 `SplitKey Virtual Mouse`, `Classes: CURSOR \| EXTERNAL`。自绘箭头早期做过，追不上系统光标速度，已删 |
| `2  中文输入（Rime）` + `候选直接浮在上屏光标下方` | 接 librime，`CapsuleView` 画在上屏光标下方；不是系统输入法那套弹窗 |
| `3  防烧屏` + `闲置变暗/收起，亮度无极可调（OLED 必做）` | 这台机的系统 `burn_in_protection=0`、下屏 `brightnessDim=-1`（永不自动变暗）。不做就烧屏，所以这是**必须做**而非加分项 |

## 第 5 段：录屏操作顺序

`shoot.sh` 里的点击序列（下屏 1280×960 实测坐标）：

```
n (764,723) → i (846,519) → 空格 (754,900)
→ 逗号 (988,795) → 句号 (1112,795) → 退格 (1210,519) ×2
```

意图：打「ni」出候选组 → 空格选第一个 → 打中文标点 → 退格演示删除。
16 秒够一遍完整流程，不需要剪。

**注意**：录屏只能录一个 display。上屏是主体，下屏靠第 3、6 段的静帧交代。

## 文案调性

- 不用感叹号，不用「革命性」「颠覆」这类词
- 每条字幕都是一个**可验证的事实**，不是形容
- 中文，技术词保留英文（uinput、Rime、OLED）

## 音乐

`video/assets/bgm.m4a` 放进去就会自动混音（`-shortest` 对齐）。
没有也能出片，只是静音。建议节奏平缓、无人声，避免压过字幕。

## 换画面的方法

时长集中在 `make-video.sh` 第 56 行：

```bash
S1=9; S2=11; S3=13; S4=15; S5=16; S6=11; S7=9; S8=6   # 合计 90s
```

改数字就改时长，不用碰滤镜。加段就复制一个 `ffmpeg` 块 + 在拼接循环里加序号。
